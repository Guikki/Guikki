# 🧬 DocDNA

<div align="center">

![Status](https://img.shields.io/badge/STATUS-IN_DEVELOPMENT-7C3AED?style=for-the-badge)
![Focus](https://img.shields.io/badge/FOCUS-DOCUMENT_INTELLIGENCE-EC4899?style=for-the-badge)
![Backend](https://img.shields.io/badge/BACKEND-FASTAPI-22D3EE?style=for-the-badge&logo=fastapi&logoColor=0B1020)

### Document Intelligence & Antifraud Platform

</div>

**DocDNA** is a modular full stack application designed for forensic document analysis and antifraud investigations.

Instead of relying on a single indicator, the platform combines multiple independent analysis layers to identify inconsistencies between textual, visual, structural and metadata evidence.

### 🔬 Current analysis capabilities

- OCR and text extraction
- PDF structural analysis
- metadata extraction
- barcode analysis
- document comparison
- visual evidence detection
- batch processing
- investigation workflows
- structured reporting
- automated testing
- modular backend architecture

### 🧰 Stack

`Python` · `FastAPI` · `OpenCV` · `Tesseract OCR` · `PyMuPDF` · `Jinja2` · `HTML` · `CSS` · `JavaScript` · `pytest`

> **The goal is not simply to extract information from documents, but to understand whether different pieces of evidence are consistent with each other.**
