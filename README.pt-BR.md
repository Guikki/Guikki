# 🧬 Projeto Principal

## DocDNA

### Plataforma de Inteligência Documental e Antifraude

O **DocDNA** é uma aplicação modular voltada à análise forense de documentos e investigação de possíveis fraudes.

O projeto combina diferentes técnicas independentes de análise para investigar documentos PDF e identificar inconsistências entre evidências textuais, visuais e estruturais.

### Algumas funcionalidades

- OCR e extração de texto
- análise estrutural de PDFs
- extração de metadados
- análise de códigos de barras
- comparação entre documentos
- detecção de evidências visuais
- processamento de documentos em lote
- fluxo de investigações
- exportação de relatórios em Excel
- testes automatizados
- arquitetura backend modular

### Stack

`Python` · `FastAPI` · `OpenCV` · `Tesseract OCR` · `PyMuPDF` · `Jinja2` · `HTML` · `CSS` · `JavaScript` · `pytest`

> O objetivo não é apenas extrair informações dos documentos, mas compreender se diferentes evidências são consistentes entre si.
